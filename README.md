# CRIMSON TIER — Персональный медиа-тир-лист

Интерактивное веб-приложение для составления персональных тир-листов просмотренных **аниме** и **фильмов** в минималистичном дизайне (Human-Crafted Minimal UI: стандарты Linear, GitHub, Vercel) на базе темного графита и сдержанного красного акцента.

Проект расположен в:
`C:\Users\user\.gemini\antigravity\scratch\media_tierlist`

---

## Основной функционал

1. **Доска рангов с фильтрами и поиском**:
   - Переключение категорий: **«Все»**, **«Фильмы»**, **«Аниме»** с динамическими бейджами количества.
   - Живой поиск по названию тайтла, оригинальному названию и году выпуска в реальном времени.
2. **Добавление контента**:
   - **Онлайн-поиск (API)**: поиск аниме (Kitsu / Jikan / Shikimori) и фильмов (Cinemeta / IMDb) с автоподтягиванием названий, постеров, года и рейтинга.
   - **Вручную (с ПК или по URL)**: загрузка изображений прямо с компьютера через HTML5 FileReader (с автоматической компрессией) либо ввод прямой ссылки на постер.
3. **Карточки тайтлов**:
   - В покое: чистые постеры высокого разрешения без визуального шума.
   - При наведении (hover): строгая инфо-плашка с полным названием, типом контента, рейтингом, годом и хронометражем/эпизодами.
   - В банке: кнопка быстрого удаления `×` в правом верхнем углу при наведении.
   - Контекстное меню `⋮` в верхнем левом углу для быстрого перемещения между тирами без использования drag & drop.
4. **Управление уровнями (тирами)**:
   - Уровни по умолчанию: **S+**, **S**, **A**, **B**, **C**, **D** в сдержанной красно-бордовой палитре.
   - Добавление новых уровней, перемещение уровней выше/ниже, возврат карточек уровня в банк, удаление уровня.
   - Настройка названия и выбор цвета из палитры или колорпикера.
5. **Банк нераспределенного контента**:
   - Сортировка банка: по алфавиту (**А-Я**), по оценке, по году, сброс к исходному порядку.
   - Кнопка **«Вернуть всё в банк»** для очистки всей доски в один клик.
6. **Экспорт и сохранение**:
   - **Скачивание PNG в высоком разрешении** (Ultra HD 2x / 3x / 1x) с заголовком и датой через высокопроизводительный Canvas 2D engine.
   - Автосохранение каждого действия в **LocalStorage**.
7. **Автономность**:
   - Работает полностью локально и оффлайн. Встроенный векторный SVG-генератор постеров гарантирует корректное отображение любых тайтлов при отсутствии сети.

## Запуск проекта

### Вариант 1: Открытие напрямую в браузере
Дважды кликните по файлу:
`C:\Users\user\.gemini\antigravity\scratch\media_tierlist\index.html`
или откройте его в Google Chrome / Microsoft Edge.

### Вариант 2: Локальный веб-сервер через Python
В терминале:
```powershell
python -m http.server 8080 --directory "C:\Users\user\.gemini\antigravity\scratch\media_tierlist"
```
После чего откройте: `http://localhost:8080`
